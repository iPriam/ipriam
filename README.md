Hi, I’m Priam

I build open-source developer infrastructure, mostly around Kira: a dual-mode programming language and toolchain that can run code through a bytecode VM, emit LLVM/native executables, or mix runtime and native execution in the same project.

Most of my active open-source work lives in @kira-lang-com, including:

* Kira, compiler, VM, LLVM/native backend, CLI, package tooling, and language tests
* Kira Graphics, rendering API and graphics runtime work
* Kira Layout, geometry and layout engine foundations
* UI Foundation, UI infrastructure for the Kira ecosystem
* Kira UI, SwiftUI Like framework for building apps
* Editor toolin, VS Code and Zed integration

I also work on infrastructure projects like MeshScale, and I like building systems that connect language design, tooling, graphics, apps, and cloud platforms into one coherent stack.

Currently focused on making Kira easier to build, test, and contribute to.
